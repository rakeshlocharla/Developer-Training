The commands i learned today are
1. git init - to initialize empty git
2. git status - to check status of my repo (untracked, modified, deleted, staged etc..)
3. git add - adds the existing file to staging area
4. git commit - commits my changes like taking a snapshot of staged 
5. git push - push my existing files in local repo to remote repo
6. git log - displays info such as author, date, commit mesg
7. git clone url - creates clone of remote repo into local repo
8. git remote add origin url - save the git address and tells the git where to upload
9. git branch main - rename the current branch
10. git push -u origin main - sends your commit to github
